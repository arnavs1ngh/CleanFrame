# Launcher wallpapers

Each entry in `SOURCES.json` (fifteen Unsplash-licensed, plus any owner-supplied personal photos such as `family`) has a background JPEG, a thumbnail and a small blurred panel backdrop. Four registered material JPEGs per image live in `../materials/`. All derived images retain the source photograph's terms.

Photo pages, authors and licence observations are in [asset sources](../../../docs/asset-sources.md). Generation instructions are in [asset generation](../../../docs/assets.md). Full-size originals remain outside the repository.
